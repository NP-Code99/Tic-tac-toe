## 📌 Overview

A fully featured **2-player Tic-Tac-Toe** game built in Python with a graphical interface, custom image assets, and sound effects. Includes a complete **unit test suite** to verify game logic — win detection, draw conditions, and board state management.

---

## 🎮 Features

- 🖼️ **Graphical UI** — custom sprites and images for X, O, and the board
- 🔊 **Sound effects** — audio feedback on moves and game end
- 👥 **2-player local multiplayer** — take turns on the same machine
- ✅ **Win detection** — checks all rows, columns, and diagonals
- 🤝 **Draw detection** — recognizes a full board with no winner
- 🧪 **Unit tested** — `tic_tac_toe_test.py` covers core game logic

---

## 📁 Project Structure

```
Tic-tac-toe/
├── tic-tac-toe.py          # Main game loop and rendering
├── tic_tac_toe_test.py     # Unit tests for game logic
├── All Images/             # Sprite assets (X, O, board, background)
└── Sounds/                 # Audio files for moves and game events
```

## 🚀 Getting Started

### Install dependencies
```bash
pip install pygame
```

### Run the game
```bash
python tic-tac-toe.py
```

### Run unit tests
```bash
python tic_tac_toe_test.py
```

---

## 🎯 How to Play

| Action | Input |
|:---|:---|
| Place X or O | Click on any empty cell |
| Win | Get 3 in a row — horizontal, vertical, or diagonal |
| Draw | Fill the board with no winner |
| Restart | Close and relaunch |
